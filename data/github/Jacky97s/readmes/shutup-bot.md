# ShutUpBot - Automated "Polite Decline" Generator

ShutUpBot is a web application that helps you generate polite responses to decline invitations, requests, or proposals. You can include both text and multiple images in your polite declines. The application uses OpenAI's GPT-4 to generate contextually appropriate, polite responses.

## Features

- **Multiple Image Upload**: Drag and drop or select multiple images to include with your response
- **Text Input**: Paste the text you want to politely decline
- **AI-Generated Responses**: Get a unique, context-aware polite decline generated by OpenAI
- **Direct API Integration**: Uses your own OpenAI API key for secure, direct communication
- **Multi-Image Analysis**: Processes multiple images to incorporate context into the response
- **Copy to Clipboard**: Easily copy the generated response
- **Save as Image**: Download your response as an image to share
- **Client-Side Processing**: All processing happens in the browser for enhanced privacy

## Technologies Used

- **Frontend**:
  - HTML5
  - CSS3
  - JavaScript (Vanilla)
  - html2canvas (for saving responses as images)

- **Backend** (minimal static file server):
  - Node.js
  - Express.js

## Setup

### Prerequisites
- Node.js (v14 or later)
- An OpenAI API key (input directly in the application)

### Installation

1. Clone the repository
   ```
   git clone https://github.com/yourusername/shutupbot.git
   cd shutupbot
   ```

2. Install dependencies
   ```
   npm install
   ```

3. Start the server
   ```
   npm start
   ```

4. Access the application at `http://localhost:3000`

## How to Use

1. **Provide Your API Key**: Enter your OpenAI API key in the designated field and click "Save Key"
2. **Upload Images** (optional): Either drag and drop images into the upload area or click "Select Images". You can select multiple images at once (up to 6 images, 20MB total)
3. **Enter Text** (optional): Paste the text you want to decline in the text area
4. **Generate**: Click the "Generate Polite Decline" button
5. **Use Your Response**: Copy the generated text or save it as an image

## Privacy and Security

- Your OpenAI API key is stored locally in your browser using localStorage and is never sent to our servers
- The application communicates directly with OpenAI's API from your browser
- Images and text content never pass through our servers

## Supported Image Formats

- PNG
- JPEG/JPG
- GIF
- WebP
